# Python Temel Alıştırmalar

Bu repo, Python öğrenme sürecimde yaptığım küçük denemeleri ve alıştırmaları içerir.  
Amaç: temel veri tipleri, koşullar, döngüler ve string işlemleri gibi konuları pratik etmek.

## 📂 İçerik
- **01 Stringler** → String işlemleri ve metin manipülasyonu
- **02 Integer ve Float** → Sayılarla işlemler
- **03 Listeler** → Liste veri tipi ve kullanımı
- **04 Demet ve Kümeler** → Tuple ve set örnekleri
- **05 Sözlükler** → Dictionary veri tipi
- **06 If-Elif-Else** → Koşullu ifadeler
- **07 Döngüler** → For ve while döngüleri
- **08 Input** → Kullanıcıdan veri alma
- **09 Genel Tekrar Alıştırma** → Karışık pratikler
